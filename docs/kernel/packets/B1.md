## 验收标准

- 提交、查询、取消、幂等冲突检测、Bot 所属关系可靠；单 worker OS 锁；原子领取并预分配 Run/Session 关联。
- 取消正在运行的 Task 使用请求标志和 runner.cancel，不能伪造终态放任执行。
- checkpoint/finish/reconcile 按 Run 累计快照的增量只计一次预算；等待不计时间，续跑剩余额度不重置；预算耗尽不会反复领取。
- 四个崩溃窗口按契约对账；没有 Run 证据的占位领取可回收；有未定副作用的任务转 needs_reconciliation，不自动重放；resolve 必须人工说明。
- ready→wake 由 B3 调用，wake 对同一交互幂等，不让旧交互唤醒新等待；B1 不依赖 B2 的内部表。
- 报告调度异常、锁释放和关闭行为；不要静默吞持久化失败。
