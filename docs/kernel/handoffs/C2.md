## 构造与公开 API

```python
from hiro_agent.bots import BotStore
from hiro_agent.durable_tasks import TaskStore
from hiro_agent.kernel_db import KernelDatabase
from hiro_agent.skills import SkillStore

database = KernelDatabase.for_workspace(workspace)
bots = BotStore(database)
tasks = TaskStore(database, bots)
skills = SkillStore(database, bots, tasks, workspace / ".hiro-agent" / "skills")
```

构造参数依次为 `KernelDatabase, BotStore, TaskStoreService, Path`。目录参数必填，由 C4 统一选择；上述目录是推荐装配位置。构造会创建目录并应用自己的 `skills` v1 迁移。

| 方法 | 返回及行为 |
| --- | --- |
| `load(skill_id)` | `SkillDocument`，只读本地文本，不涉及某个 Bot 的启用权。 |
| `get(bot_id, skill_id)` | `SkillRecord(document, enabled, is_draft)`；Bot 必须真实存在。 |
| `list(bot_id, *, enabled_only=False)` | 按 ID 排序的 `list[SkillRecord]`。普通本地目录是共享技能目录，启用状态按 Bot 隔离。 |
| `settings(bot_id)` | `list[SkillSetting]`，包括已删文件的启停记录，便于查询和修复。 |
| `enable(bot_id, skill_id)` / `disable(bot_id, skill_id)` | `SkillSetting`；启用前验证真实文件，禁用可用于已删/损坏文件。 |
| `set_enabled(bot_id, skill_id, enabled)` | 同上，`enabled` 必须是真正的 bool。 |
| `describe(bot_id)` | 已启用技能的名称、ID、说明组成的 prompt 文本；等价于默认 `injection`。 |
| `content(bot_id, skill_id)` | 已启用技能正文；未启用抛 `ConfigurationError`。 |
| `injection(bot_id, *, include_content=False)` | fresh prompt 文本；True 包含正文，False 只有说明。无启用技能返回空字符串。 |
| `draft_from_task(bot_id, task_id)` | `SkillDraft(bot_id, task_id, document, created_at)`；必须显式调用，不自动启用。 |

`SkillDocument` 是冻结 dataclass，字段 `id, name, description, content, path, digest`；content 不含 frontmatter，digest 为原文件字节 SHA-256。`SkillSetting` 字段 `bot_id, skill_id, enabled, updated_at`。其余 DTO 同样冻结。

## Markdown 与文件边界

接受 `<id>.md` 或 `<id>/SKILL.md`，同一 ID 同时存在两种文件时报错。ID 只允许 1–128 位 ASCII 字母数字、下划线和连字符，首字符必须字母数字；没有任意路径导入/执行 API。文件 UTF-8、最多 1 MiB，读取使用目录描述符、`O_NOFOLLOW` 和普通文件校验；文件/子目录符号链接及 FIFO 被拒绝，目录初始化后被换成符号链接也被拒绝。传入的目录在初始化时解析为固定绝对边界。

可选 frontmatter 支持单行 `name`、`description`、JSON 双引号文本、YAML 单引号文本，以及 `|`/`>`（含 `+`/`-`）的缩进多行说明。这是明确的小型文本子集，不是完整 YAML 解析器；不支持的 name/description 结构、重复字段、未闭合 frontmatter、空正文、无说明或无效 UTF-8 均给出 `ConfigurationError`。其他元数据只作为无效力的文本跳过，不解释权限、命令、脚本或授权。

没有 frontmatter 时，name 从第一个一级标题取得（否则使用 ID），description 从首个非空说明段落提取。文件编辑在下次读取立即生效。缺失/损坏的已启用文件明确报错，不悄悄沿用缓存；可显式 disable 后恢复注入。

```markdown
---
name: Inspect evidence
description: Inspect local files and cite the evidence before reporting.
---

# Inspect evidence

Read the relevant files and include exact source locations in the report.
```

## C4 注入与显式草稿示例

```python
skills.enable("inspector", "inspect")
description_fragment = skills.describe("inspector")
body = skills.content("inspector", "inspect")
full_fragment = skills.injection("inspector", include_content=True)

draft = skills.draft_from_task("inspector", succeeded_task_id)
assert not skills.get("inspector", draft.document.id).enabled
review_path = draft.document.path
# 用户检查并编辑该文件后，才由显式启用操作执行下一行。
skills.enable("inspector", draft.document.id)
```

C4 在适当的新 Task/Run prompt 装配点读取注入片段；本模块不会修改历史 Session、工具 schema、执行器 policy 或权限配置。description 模式用于展示和选择，content 模式仅在对应 Bot 已启用时提供正文。目录共享不等同于自动启用，另一个 Bot 默认没有该技能注入。

草稿生成每次通过公开 `tasks.get(task_id, bot_id=bot_id)` 重新验证真实 `succeeded` 状态及非空结果。queued/running/failed/cancelled/needs_reconciliation/无交互暂停失败均拒绝，错误 Bot 或未知 Task 也拒绝；不会接受调用者自称成功的 Task DTO。草稿保存原任务、成功结果及 Bot/Task/Session/revision 来源，围栏长度会避开结果内已有反引号，供人工编辑成可复用说明。

## 持久化与权限证据

只通过公开数据库接口修改本模块 `skill_settings`、`skill_drafts` 表。前者以 `(bot_id, skill_id)` 持久保存启停；后者以 `(bot_id, task_id)` 保存固定草稿 ID、原 Markdown、创建时间及发布标记。不写 Bot、Task、Run、交互或授权的内部表，不调用 `BotStore.save`，不解释技能文本中的授权声明。

草稿 ID 为 Bot/Task 组合的 SHA-256，跨进程/重复请求相同。先保存 SQL 创建意图，退出事务后写临时文件、fsync、原子 hard-link 发布（不覆盖目标），最后标记 published。文件 I/O 不在 SQL 事务内。

- SQL 已提交、文件未发布：重复调用从已存 Markdown 修复。
- 文件已发布、SQL 未标记：只接受字节完全相同的文件，再完成标记；冲突明确报错并保留文件。
- 已发布且人工编辑：重复调用保留当前文件与最初创建时间；损坏的编辑报解析错误，也不覆盖。
- 已发布文件被删除：显式重复生成会从原 Markdown 恢复。启用状态始终不由生成操作修改。
- 同任务并发生成：SQL 唯一键和文件无覆盖发布保证只有一个完整 Markdown；不同内容、目录同名技能、符号链接均拒绝覆盖。硬崩溃可能留下隐藏的临时文件，它不会被枚举为技能。

`test_skill_claims_cannot_grant_tools_or_bypass_real_executor_policy` 使用真实 BotStore、PermissionPolicy、ToolExecutor：技能声称 unrestricted/approved 并要求写文件，启用/注入/禁用后 Bot 完整记录和权限版本仍不变。未获白名单的 write_file 返回 `permission_denied/not_started`；已有白名单但审批拒绝同样不执行；没有 tool.started 或实际文件。C4/R3 再验证组合运行时中的同一边界。
